# Student Task Manager

A simple and user-friendly web application to manage daily tasks efficiently.

## Features

- Add new tasks
- Set task priority
- Set due date
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Track total, completed and pending tasks
- Store tasks using browser Local Storage

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding and managing your tasks.

## Project Purpose

This project was developed to practice front-end web development and JavaScript concepts such as DOM manipulation and Local Storage.
